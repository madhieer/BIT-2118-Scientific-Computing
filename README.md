# BIT 2118 – Scientific Computing

## Project Overview
This repository contains group research, documentation,
Python demonstrations and visualizations for Scientific Computing.

## Project Objectives
- Explain 19 scientific computing topics.
- Demonstrate numerical methods using Python.
- Interpret numerical outputs and graphs.
- Explore practical applications of scientific computing.

## Technologies Used
- Python
- NumPy
- SciPy
- Matplotlib
- Jupyter Notebook

## Project Structure
- documentation: Project handout
- python_demos: Python source code
- graphs: Generated visualizations
- presentation: Group presentation slides

10 Members
